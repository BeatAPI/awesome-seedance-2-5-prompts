## Source policy

The catalog only marks a creator example `source-verified` when an X post or
same-author thread provides all three pieces of evidence:

1. explicit Seedance 2.5 model attribution;
2. the output video;
3. the reusable generation prompt.

Official examples remain separately labeled. Public source availability is
not treated as a transfer of media or prompt copyright.
