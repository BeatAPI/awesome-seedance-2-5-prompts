- 295 条创作者来源核验案例；

  画幅、验证状态和权利状态。

只有在原视频、操作 Prompt 与输出结果可以一一核验时才会加入。

- `template-unverified`：没有公开输出证据的编辑模板；首批目录没有把
  这种模板混入真实案例。

`prompt-gallery/seedance-2-5/` 路径。

原始 X 帖子和作者是署名依据。公开发布不等于版权转移；第三方 Prompt
